# Tomphil Logistics

> **"Your Logistics. Our Priority."**

Official corporate web application and logistics platform for **Tomphil Logistics**, specializing in customs clearing (vehicles & goods) into and out of Zimbabwe, cross-border freight forwarding, and international multimodal transport.

---

## 🚀 Key Features

- **Zimbabwe Customs & Vehicle Duty Calculator**: Interactive instant estimation for vehicle imports (Sedans, SUVs, Light Trucks, Heavy Duty) factoring CIF, Customs Duty, Surtax, and VAT according to ZIMRA regulations.
- **Dedicated Multi-Page Architecture**:
  - / — Homepage featuring realistic vehicle motion, service matrix, port coverage, tracking preview, and testimonials.
  - /about — Executive profile, leadership, mission, vision, and border post network.
  - /services — Comprehensive logistics solutions and trade facilitation.
  - /car-clearing — Zimbabwe vehicle clearance, duty calculator, document checklist, and port-to-door forwarding.
  - /goods-clearing — Commercial freight, industrial equipment, agricultural inputs, and compliance.
  - /global-transport — Multimodal sea, air, and road freight routes across Africa, Asia, Europe, and Americas.
  - /why-choose-us — Strategic differentiators, security protocols, and customs expertise.
  - /track-trace — Interactive consignment tracking portal with live milestones.
  - /quote — Detailed quote request builder with multi-step logistics specs.
  - /contact — Harare HQ & Beitbridge border branch details, direct inquiry form, and live maps.
- **Natural Motion Hero**: Realistic aerodynamic aircraft cruising and highway vehicle motion with suspension response and asphalt grounding.
- **Direct WhatsApp & Quote Flow**: 1-click WhatsApp escalation for emergency clearance and freight dispatch.
- **Responsive & High-Performance**: Optimized with Tailwind CSS, Lucide icons, and modern React 18 / Vite architecture.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Routing**: React Router DOM (v6)
- **Styling**: Tailwind CSS + Custom Animations
- **Icons**: Lucide React
- **Brand Palette**: Deep Navy (#0A1931), Executive Blue (#15325B), Radiant Gold (#F59E0B), Slate Gray (#64748B)

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
`ash
# Clone the repository
git clone https://github.com/mufaronoah2005-sys/tomphillogistics.git

# Navigate to the project directory
cd tomphillogistics

# Install dependencies
npm install

# Start the development server
npm run dev
`

### Production Build
`ash
npm run build
npm run preview
`
